# 번역캣 (translation-cat)

**실시간 화면·클립보드 텍스트 번역기**  
- **기술 스택**: Python, PyQt6, Google/DeepL API  
- **기능**:
  1. 클립보드 감지 → 번역
  2. 드래그 텍스트 번역
  3. 시스템 트레이 아이콘

## 설치

```bash
pip install -r requirements.txt
python translation_cat.py
```
